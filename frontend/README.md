# Smart Shelf Intelligence System - Frontend

React/Vite frontend for visualizing shelf data, events, and analytics.

## Features

- **Real-time Dashboard**: Live camera feed and event logs.
- **Inventory View**: Current stock levels and alerts.
- **Analytics**: Charts and graphs for customer behavior.
- **Configuration**: System settings.

## Development

### Requirements
- Node.js 18+

### Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
   Access at `http://localhost:3000`.

## Docker
The frontend is designed to run in a Docker container (see root `docker-compose.yml`).
